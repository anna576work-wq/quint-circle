# Quint Circle

Интерактивный конструктор музыкальных аккордов с фиксированным хроматическим кругом из 12 звуковысотных классов. Приложение построено на React, TypeScript, Vite и `@tonaljs/tonal`.

## Запуск

Требуется Node.js 18 или новее.

```bash
npm ci
npm run dev
```

Откройте адрес, показанный Vite в терминале (обычно `http://localhost:5173/quint-circle/`).

## Проверки и production-сборка

```bash
npm test
npm run build
npm run preview
```

Vite base path настроен на `/quint-circle/` для GitHub Pages.

## Конструктор

- Круг содержит 12 фиксированных звуковысотных классов; ноту можно выбрать нажатием или клавиатурой.
- Каталог включает 43 типа: от трезвучий и sus до септаккордов, 6/9, add, 9/11/13 и альтерированных аккордов.
- Для каждого типа отображаются интервальная формула, теоретически написанные ноты и краткое объяснение.
- Настройки включают диезное, бемольное и автоматическое написание, буквенные и русские названия.
- Основной тон, тип аккорда и настройки сохраняются в localStorage с проверкой версии и безопасным fallback.

Пианино, гитарные аппликатуры, воспроизведение, последовательности и рекомендации запланированы на следующие этапы.
