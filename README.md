# Quint Circle

Интерактивный конструктор музыкальных аккордов на основе хроматического круга. Приложение написано на React, TypeScript и Vite, интерфейс на русском языке.

## Запуск

Требуется Node.js 18 или новее.

```bash
npm ci
npm run dev
```

Откройте адрес, показанный Vite в терминале (обычно `http://localhost:5173/quint-circle/`).

## Проверки и сборка

```bash
npm test
npm run build
npm run preview
```

Production-сборка настроена для GitHub Pages по пути `/quint-circle/`.
