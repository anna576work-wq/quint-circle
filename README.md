# Quint Circle

Интерактивный квинтовый круг и справочник диатонических аккордов. Интерфейс на русском языке, приложение работает в браузере.

## Запуск

Требуется Node.js 18 или новее.

```bash
npm install
npm run dev
```

Откройте адрес, показанный Vite в терминале (обычно `http://localhost:5173/quint-circle/`).

## Сборка

```bash
npm run build
npm run preview
```

Сборка настроена для размещения в GitHub Pages по пути `/quint-circle/`.

## Этап 1

- SVG-квинтовый круг с выбором мажорной и минорной тональности.
- Относительные тональности и знаки при ключе.
- Гамма и семь диатонических трезвучий выбранного лада.
- Тёмный адаптивный интерфейс.

Последующие функции описаны в `PLAN.md`.
