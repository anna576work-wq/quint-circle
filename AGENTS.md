# Правила работы над Quint Circle

- Интерфейс приложения и пользовательская документация — на русском языке.
- Сначала проверяй фактическую работу музыкальных вычислений, затем оформляй интерфейс.
- Не добавляй декоративные элементы управления без работающего действия.
- Не изменяй существующие пользовательские файлы без необходимости.
- После завершения этапа запускай доступные проверки и обновляй `PLAN.md`.
- До отдельного подтверждения пользователя не публикуй приложение и не объединяй изменения в основную ветку.
